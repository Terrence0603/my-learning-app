#### 什麼是「預訓練模型」？

想像你買了一個已經設定好的智慧家電，它已經知道如何執行某些任務。預訓練模型就是類似的概念：它是一個已經看過大量數據、學習了數據中潛在模式的機器學習模型。這個模型被訓練完成後，通常會被儲存成一個檔案，像是 `.pkl` (pickle) 或 `.joblib` 格式。

為什麼要導入預訓練模型呢？

1.  **省時省力**：訓練一個模型可能需要大量的數據、計算資源和時間。直接使用預訓練模型可以省去這些麻煩。
2.  **利用專家成果**：許多複雜的模型是由研究人員或專家訓練出來的，我們可以直接利用他們的成果。
3.  **快速部署**：在實際應用中，我們經常需要快速地將模型整合到應用程式中，導入預訓練模型是最直接的方式。

**第一步：創建並保存一個「假想」模型 (只運行一次)**

我們將使用 `scikit-learn` 函式庫來創建一個簡單的線性迴歸模型。這個模型將學習如何根據房屋的大小來預測房價。

```python
import joblib
from sklearn.linear_model import LinearRegression
import numpy as np

# 1. 假裝我們已經有了一些訓練數據 (非常簡化，只為示範)
# X_train: 房屋大小 (平方公尺)
# y_train: 對應的房價 (萬元)
X_train = np.array([10, 20, 30, 40, 50]).reshape(-1, 1) # 注意：sklearn 要求輸入數據是 2D 陣列
y_train = np.array([100, 200, 280, 390, 510])

# 2. 訓練一個簡單的線性回歸模型
print("正在訓練一個簡單的房屋價格預測模型...")
model = LinearRegression()
model.fit(X_train, y_train)
print("模型訓練完成！")

# 3. 將這個模型保存起來
filename = 'my_house_price_predictor.joblib'
joblib.dump(model, filename)
print(f"模型已保存為 {filename}")

print("\n你現在可以在同一個資料夾下找到 'my_house_price_predictor.joblib' 這個檔案。")
print("這個檔案就是我們等等要導入的預訓練模型！")
```
運行上面的程式碼後，你就會在你的程式碼檔案所在的資料夾裡，看到一個叫做 `my_house_price_predictor.joblib` 的檔案。這個檔案就是我們的「預訓練模型」！

**第二步：載入模型並進行預測**

現在，想像一下，過了一段時間，你關掉了程式，或者把這個模型檔案分享給了你的朋友。現在我們來學習如何「導入」這個模型，並用它來預測新的數據！

```python
import joblib
import numpy as np

# 定義模型檔案的路徑
filename = 'my_house_price_predictor.joblib'

# 載入之前保存的模型
try:
    loaded_model = joblib.load(filename)
    print(f"模型 '{filename}' 已成功載入！")
except FileNotFoundError:
    print(f"錯誤：找不到模型檔案 '{filename}'。請確認檔案是否在正確的位置，或者先運行上方的『創建並保存模型』程式碼。")
    exit()

# 準備新的數據進行預測
# 假設我們想預測一個 35 平方公尺的房子價格
# 注意：輸入數據也必須是 2D 陣列 (例如 [[35]])
new_house_size = np.array([[35]])

# 使用載入的模型進行預測
predicted_price = loaded_model.predict(new_house_size)

print(f"\n--- 預測結果 ---")
print(f"預測 35 平方公尺的房子價格約為：{predicted_price[0]:.2f} 萬元") # 使用 [0] 取得陣列中的值，並格式化輸出

# 我們可以再預測一個不同的尺寸
another_house_size = np.array([[60]])
another_predicted_price = loaded_model.predict(another_house_size)
print(f"預測 60 平方公尺的房子價格約為：{another_predicted_price[0]:.2f} 萬元")

print("\n恭喜你！你已經成功導入並使用了機器學習模型進行預測！")
```
