### 【第 14 天：例外處理 (Try/Except) – 讓你的程式更強壯！】

想像一下，你在玩一個很酷的遊戲，玩到一半突然畫面卡住、然後跳出一個錯誤訊息，最後遊戲直接關閉了！是不是很掃興？

在程式設計的世界裡，這種情況叫做「程式崩潰」或「當機」。當你的程式在執行過程中，遇到一些它無法處理的狀況時，就會發生這種事。這些「無法處理的狀況」我們稱之為**例外 (Exception)** 或 **錯誤 (Error)**。

例如：
*   你要求使用者輸入一個數字，但他卻輸入了文字。
*   你試圖打開一個不存在的檔案。
*   你計算時，不小心讓除數變成了零。

當這些情況發生時，如果不做任何處理，你的程式就會像前面說的遊戲一樣，直接中止，並印出一大串紅色的錯誤訊息，讓使用者摸不著頭緒。這時候，我們就需要「例外處理」這位超級英雄出場了！

---

#### 1. 當「錯誤」來敲門：沒有例外處理的世界

讓我們先看看一個沒有例外處理的程式會是什麼樣子。想像我們要請使用者輸入兩個數字，然後計算它們的商：

```python
print("--- 商數計算機 ---")
try:
    num1_str = input("請輸入第一個數字: ")
    num1 = int(num1_str) # 這裡可能會出錯

    num2_str = input("請輸入第二個數字: ")
    num2 = int(num2_str) # 這裡也可能會出錯

    result = num1 / num2 # 如果 num2 是 0，這裡會出錯
    print(f"結果是: {result}")
except ValueError:
    print("輸入錯誤！請確保你輸入的是有效的數字。")
except ZeroDivisionError:
    print("糟糕！除數不能為零哦！")
except Exception as e:
    print(f"發生了未預期的錯誤: {e}")

print("程式執行完畢。")
```

**執行看看，如果你輸入了文字或 0：**

```
請輸入第一個數字: hello
Traceback (most recent call last):
  File "your_program.py", line 4, in <module>
    num1 = int(num1_str)
ValueError: invalid literal for int() with base 10: 'hello'
```
哇！程式直接中止了，而且印出了 `ValueError` 的錯誤訊息，對初學者來說可能很難懂。

---

#### 2. 拯救世界的英雄：`try` 和 `except`

這時候，我們的救星 `try` 和 `except` 就派上用場了！

*   `try` 區塊：把你覺得「可能會出錯」的程式碼放進來。Python 會嘗試執行 `try` 區塊裡的程式碼。
*   `except` 區塊：如果 `try` 區塊裡的程式碼真的出錯了，Python 會立刻跳到 `except` 區塊，執行你預先準備好的「備用方案」或「錯誤處理」程式碼。

讓我們用 `try` 和 `except` 來改造上面的計算機：

```python
print("--- 商數計算機 (加強版) ---")

try:
    num1_str = input("請輸入第一個數字: ")
    num1 = int(num1_str) # 嘗試將輸入轉換為整數

    num2_str = input("請輸入第二個數字: ")
    num2 = int(num2_str) # 嘗試將輸入轉換為整數

    result = num1 / num2 # 嘗試進行除法運算
    print(f"結果是: {result}")

except ValueError:
    # 如果 try 區塊發生 ValueError (例如輸入了文字而不是數字)
    print("輸入錯誤！請確保你輸入的是有效的數字。")

except ZeroDivisionError:
    # 如果 try 區塊發生 ZeroDivisionError (例如第二個數字輸入了 0)
    print("糟糕！除數不能為零哦！請輸入一個非零的數字。")

except Exception as e:
    # 這是通用的例外處理，可以捕獲任何其他未預期的錯誤
    # `as e` 可以讓我們拿到錯誤的具體訊息
    print(f"發生了未預期的錯誤: {e}")

print("程式執行完畢。") # 無論有沒有錯誤，這行都會執行 (除非程式被強制關閉)
```

**現在，再試著輸入文字或 0 看看：**

*   **輸入 `hello` 作為第一個數字：**
    ```
    --- 商數計算機 (加強版) ---
    請輸入第一個數字: hello
    輸入錯誤！請確保你輸入的是有效的數字。
    程式執行完畢。
    ```
*   **輸入 `10` 和 `0`：**
    ```
    --- 商數計算機 (加強版) ---
    請輸入第一個數字: 10
    請輸入第二個數字: 0
    糟糕！除數不能為零哦！請輸入一個非零的數字。
    程式執行完畢。
    ```
*   **輸入 `10` 和 `2` (正確情況)：**
    ```
    --- 商數計算機 (加強版) ---
    請輸入第一個數字: 10
    請輸入第二個數字: 2
    結果是: 5.0
    程式執行完畢。
    ```

看到了嗎？這次程式沒有直接崩潰，而是根據錯誤類型，印出了友善的提示訊息，然後程式繼續執行到最後一行！這就是例外處理的魔力！你的程式變得更「貼心」也更「堅固」了。

---

#### 3. 各式各樣的 `except`

*   **捕捉特定的例外：** 就像上面範例的 `except ValueError:` 和 `except ZeroDivisionError:`，你可以為不同的錯誤類型提供不同的處理方式。這是最推薦的做法，因為它能讓你的錯誤處理更精確。
*   **捕捉所有例外：** `except Exception as e:` 是一個通用的例外處理。它會捕捉所有繼承自 `Exception` 的錯誤（幾乎所有 Python 內建的錯誤都屬於這一類）。`as e` 語法會將錯誤訊息儲存到變數 `e` 中，這樣你就可以印出更詳細的錯誤資訊。
    *   **小提示：** 雖然 `except Exception as e:` 很方便，但通常建議你盡可能捕捉更具體的例外。就像醫生看病，知道是「感冒」還是「骨折」會比只知道「生病了」更能對症下藥。

---

### 為什麼例外處理這麼重要？

*   **提升使用者體驗：** 使用者不會看到嚇人的紅色錯誤訊息，而是看到易懂的提示。
*   **防止程式崩潰：** 你的程式可以從容應對突發狀況，而不是直接停止運行。
*   **增加程式的健壯性 (Robustness)：** 讓你的程式在各種不確定的環境下，都能穩定可靠地運行。
*   **更方便除錯 (Debugging)：** 透過捕獲錯誤訊息，你可以更容易地找出問題所在。
