## Part 3: 探索資料的寶庫：清單與字典

### 1. 清單 (Lists)：有順序的「購物清單」

想像一下，你週末要去超市採購，你會列一張購物清單對吧？上面寫著「牛奶、雞蛋、麵包、蘋果」。這就是清單最棒的類比了！

在 Python 中，清單就像這樣：一個有順序的、可以放各種東西的集合。

*   **特點：**
    *   **有序 (Ordered)：** 每個項目都有一個編號 (索引)，從 0 開始。
    *   **可變 (Changeable)：** 你可以新增、刪除或修改清單中的項目。
    *   **允許重複 (Allows Duplicates)：** 同一個清單裡可以有重複的項目。
    *   可以儲存不同資料型態的項目 (例如：數字、文字、布林值甚至其他清單)。

#### **如何建立清單？**

我們用中括號 `[]` 來建立清單，並用逗號 `,` 分隔每個項目。

```python
# 一個水果清單
fruits = ["蘋果", "香蕉", "橘子", "蘋果"]
print(f"我的水果清單：{fruits}")

# 一個混合資料型態的清單
mixed_list = ["小明", 25, True, 175.5]
print(f"混合資料清單：{mixed_list}")
```

#### **如何存取清單中的項目？**

透過索引 (index) 來存取，記住！索引是從 `0` 開始的喔！

```python
fruits = ["蘋果", "香蕉", "橘子", "葡萄"]

print(f"清單中的第一個水果是：{fruits[0]}")  # 輸出：蘋果 (索引 0)
print(f"清單中的第三個水果是：{fruits[2]}")  # 輸出：橘子 (索引 2)

# 你也可以使用負數索引，-1 代表最後一個項目，-2 代表倒數第二個
print(f"清單中的最後一個水果是：{fruits[-1]}") # 輸出：葡萄
```

#### **清單的常用操作**

| 方法      | 說明                                                               | 範例                                                                        |
| :-------- | :----------------------------------------------------------------- | :-------------------------------------------------------------------------- |
| `append()` | 在清單的**最後**加入一個新項目。                                   | `fruits.append("奇異果")`                                                   |
| `insert()` | 在指定**位置**插入一個新項目。                                     | `fruits.insert(1, "草莓")` (在索引 1 的位置插入)                            |
| `remove()` | 刪除清單中**第一個**找到的指定項目。                               | `fruits.remove("香蕉")`                                                     |
| `pop()`   | 刪除指定索引的項目，並**返回**該項目。如果沒有指定索引，則刪除最後一個。 | `removed_fruit = fruits.pop(0)`                                             |
| `len()`   | 取得清單的長度 (有多少個項目)。                                    | `num_fruits = len(fruits)`                                                  |
| `[ ]`     | 修改指定索引的項目。                                               | `fruits[0] = "鳳梨"`                                                        |

**來看看實際範例：**

```python
shopping_list = ["牛奶", "雞蛋", "麵包"]
print(f"原始購物清單：{shopping_list}")

# 1. 新增項目：append()
shopping_list.append("蘋果")
print(f"新增蘋果後：{shopping_list}")

# 2. 在指定位置插入：insert()
shopping_list.insert(1, "優格") # 在 '雞蛋' 前面插入 '優格'
print(f"插入優格後：{shopping_list}")

# 3. 修改項目
shopping_list[0] = "低脂牛奶"
print(f"修改牛奶後：{shopping_list}")

# 4. 刪除項目：remove()
shopping_list.remove("麵包")
print(f"移除麵包後：{shopping_list}")

# 5. 刪除最後一個項目並取回：pop()
last_item = shopping_list.pop()
print(f"移除的最後一個項目是：{last_item}")
print(f"移除後購物清單：{shopping_list}")

# 6. 清單的長度：len()
print(f"購物清單還有 {len(shopping_list)} 個項目。")

# 7. 遍歷清單 (用迴圈一個一個讀取)
print("\n--- 我的購物清單 ---")
for item in shopping_list:
    print(f"- {item}")
```

### 2. 字典 (Dictionaries)：用「名稱」找資料的電話簿

清單很棒，但如果我想存的不是「第 1 個」、「第 2 個」水果，而是「某某人」的資訊，或者「某個單字」的定義呢？比如說，小明的「年齡」是 25，「城市」是台北。

這時候，字典 (Dictionaries) 就登場了！它就像一本電話簿，裡面記載著「名字」對應「電話號碼」，或者一本英漢字典，「英文單字」對應「中文解釋」。

*   **特點：**
    *   **鍵值對 (Key-Value Pairs)：** 每個項目都是一個「鍵 (Key)」和一個「值 (Value)」的組合。
    *   **無序 (Unordered)：** (在 Python 3.7 之前是無序的，之後是按插入順序排序，但我們通常不依賴它的順序)。
    *   **可變 (Changeable)：** 你可以新增、刪除或修改字典中的鍵值對。
    *   **鍵必須唯一且不可變：** 每個鍵都是獨特的，而且不能是可變的資料型態 (例如清單)。

#### **如何建立字典？**

我們用大括號 `{}` 來建立字典，並用 `key: value` 的形式定義每個鍵值對。

```python
# 一個學生資料的字典
student = {
    "name": "陳小花",
    "age": 18,
    "grade": "高三",
    "city": "台中"
}
print(f"學生資料：{student}")

# 一個商品價格的字典
prices = {
    "蘋果": 30,
    "香蕉": 25,
    "橘子": 40
}
print(f"商品價格：{prices}")
```

#### **如何存取字典中的值？**

我們透過「鍵 (key)」來存取對應的「值 (value)」。

```python
student = {
    "name": "陳小花",
    "age": 18,
    "grade": "高三",
    "city": "台中"
}

print(f"學生姓名是：{student['name']}") # 使用鍵 'name' 取得值
print(f"學生年齡是：{student['age']}")
```
**注意：** 如果你嘗試存取一個不存在的鍵，會發生錯誤 (KeyError)。

#### **字典的常用操作**

| 方法         | 說明                                          | 範例                                                                        |
| :----------- | :-------------------------------------------- | :-------------------------------------------------------------------------- |
| `[ ]`        | 存取或修改指定鍵的值。如果鍵不存在，則新增。  | `student["city"] = "高雄"` (修改) <br> `student["hobby"] = "閱讀"` (新增) |
| `del`        | 刪除指定鍵及其對應的值。                      | `del student["grade"]`                                                      |
| `keys()`     | 返回所有鍵的清單。                            | `student.keys()`                                                            |
| `values()`   | 返回所有值的清單。                            | `student.values()`                                                          |
| `items()`    | 返回所有鍵值對的清單 (每個都是一個元組)。     | `student.items()`                                                           |
| `len()`      | 取得字典中有多少個鍵值對。                    | `len(student)`                                                              |

**來看看實際範例：**

```python
user_profile = {
    "username": "coder_xiaoming",
    "email": "xiaoming@example.com",
    "is_active": True
}
print(f"原始使用者資料：{user_profile}")

# 1. 新增資料
user_profile["age"] = 30
print(f"新增年齡後：{user_profile}")

# 2. 修改資料
user_profile["email"] = "ming.new@example.com"
print(f"修改信箱後：{user_profile}")

# 3. 刪除資料
del user_profile["is_active"]
print(f"刪除啟用狀態後：{user_profile}")

# 4. 取得所有鍵
print(f"\n所有鍵：{user_profile.keys()}")

# 5. 取得所有值
print(f"所有值：{user_profile.values()}")

# 6. 遍歷字典 (用迴圈讀取所有鍵和值)
print("\n--- 使用者詳細資料 ---")
for key, value in user_profile.items():
    print(f"{key}: {value}")

print(f"\n字典中有 {len(user_profile)} 個項目。")
```

### 小結與練習

*   **清單 (Lists)** 適合用在需要**順序**、或只是單純收集一堆東西時，例如：學生名單、購物清單、遊戲物品列表。
