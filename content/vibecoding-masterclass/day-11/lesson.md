### 【第 11 天：Part 3: 函式 (Functions)】：程式碼的魔法整理術！

到目前為止，你已經學會了變數、資料型態、條件判斷 (if/else) 和迴圈 (for/while)。這些都是組成程式的基本磚塊。但當你的程式碼越來越長，你會不會覺得有些部分重複寫了又寫？或者一大串程式碼看起來很雜亂，很難一眼看出它在做什麼？

這時候，函式就登場啦！✨

#### 什麼是函式？

簡單來說，**函式就是一個「被命名」的程式碼區塊，它專門用來執行某個特定的任務。**
想像你正在寫一本食譜：

*   `做一道蛋炒飯()` 是一個函式。
*   這個函式裡面包含了 `打蛋()`, `切蔥()`, `炒飯()` 等小步驟。

當你想做蛋炒飯時，你只需要說 `做一道蛋炒飯()`，而不需要每次都重複寫 `打蛋`、`切蔥`、`炒飯` 的完整步驟。是不是方便多了？

在 Python 中，我們使用 `def` 關鍵字來定義一個函式。

#### 函式初體驗：定義與呼叫函式

讓我們來定義一個最簡單的函式，它只會印出一句歡迎訊息。

```python
# 使用 def 關鍵字來定義函式
# say_hello 是函式的名稱
# 括號 () 裡面是參數，目前沒有，所以是空的
# 冒號 : 表示函式區塊的開始
def say_hello():
    # 函式內的程式碼必須縮排
    print("哈囉！歡迎來到函式世界！")
    print("這是一個簡單的函式範例。")

# --- 函式定義結束，現在要來使用它囉！ ---

# 呼叫 (Call) 函式：輸入函式名稱後加上括號 ()
print("程式開始囉！")
say_hello() # 第一次呼叫函式
print("函式執行完畢！")
say_hello() # 第二次呼叫函式，你可以重複呼叫它！
print("程式結束了！")
```

**程式碼解析：**
*   `def say_hello():`：我們定義了一個名為 `say_hello` 的函式。
*   `print(...)`：函式內部的程式碼。注意它們都縮排了，這告訴 Python 這些行是 `say_hello` 函式的一部分。
*   `say_hello()`：這就是「呼叫」函式。當 Python 看到這行時，它會跳到 `say_hello` 函式的定義處，執行裡面的所有程式碼，執行完畢後再回到呼叫的地方繼續往下執行。

#### 讓函式更聰明：傳入參數 (Arguments)

目前 `say_hello()` 函式每次都說一樣的話，有點無聊對不對？如果我們希望函式能根據不同的輸入，做不同的事情呢？這時候就需要「參數」了！

參數就像是函式接收的「資訊」或「材料」。

```python
def greet_person(name): # name 就是這個函式的參數
    print(f"哈囉，{name}！很高興見到你！")
    print("希望你今天過得愉快！")

# 呼叫函式時，在括號內傳遞參數值
greet_person("小明") # 將 "小明" 這個字串傳給函式中的 name
greet_person("程式新手") # 將 "程式新手" 傳給 name
greet_person("Alice")
```

**程式碼解析：**
*   `def greet_person(name):`：我們定義了一個函式 `greet_person`，它需要一個參數，我們把它命名為 `name`。
*   當你呼叫 `greet_person("小明")` 時，`"小明"` 這個字串就會被賦值給函式內部使用的 `name` 變數。所以函式裡面的 `f"哈囉，{name}！..."` 就會變成 `f"哈囉，小明！..."`。
*   函式就像一個模板，參數讓這個模板可以重複使用，處理不同的資料！

#### 讓函式回傳結果：return

有時候，函式執行完畢後，你希望它能給你一個「結果」，而不是只是印出東西。例如，一個計算加法的函式，你希望它能把加總的結果給你，而不是直接在函式內部印出來。這時候，我們就用 `return` 關鍵字。

```python
def add_numbers(num1, num2): # 接收兩個數字作為參數
    sum_result = num1 + num2
    return sum_result # 將計算結果回傳給呼叫者

# 呼叫函式並將回傳值儲存起來
print("--- 加法計算機 ---")
result_a = add_numbers(5, 3) # 函式執行，回傳 8
print(f"5 + 3 的結果是：{result_a}")

result_b = add_numbers(100, 200) # 函式執行，回傳 300
print(f"100 + 200 的結果是：{result_b}")

# 你也可以直接在 print 函式裡呼叫函式，然後印出回傳值
print(f"7 + 10 的結果是：{add_numbers(7, 10)}")

# 範例：沒有 return 的函式，回傳值是什麼？
def just_print(message):
    print(message)

# 當函式沒有明確 return 任何東西時，它會隱式地回傳 None (代表「無」)
# 你可以試著印出它的回傳值
returned_value = just_print("我只會印東西！")
print(f"just_print 函式的回傳值是：{returned_value}")
```

**程式碼解析：**
*   `def add_numbers(num1, num2):`：這個函式接收兩個數字。
*   `sum_result = num1 + num2`：進行加法運算。
*   `return sum_result`：**這就是關鍵！**它會把 `sum_result` 的值「送回去」給呼叫它的地方。
*   `result_a = add_numbers(5, 3)`：`add_numbers(5, 3)` 執行後回傳了 `8`，這個 `8` 就會被賦值給 `result_a` 變數。
*   一個函式可以沒有 `return` 語句，那它預設會回傳 `None`。 `None` 在 Python 中表示「空值」或「無」。

#### 為什麼要用函式？

1.  **程式碼重用 (Reusability)**：寫一次，用多次。省時省力，就像食譜一樣！
2.  **組織與模組化 (Organization & Modularity)**：把大問題拆解成一個個小任務，每個函式負責一個小任務，程式碼更容易閱讀和理解。
3.  **易於維護和除錯 (Easier to Maintain & Debug)**：如果某個功能出錯了，你只需要檢查對應的函式，而不是整個程式碼。
4.  **提高可讀性 (Readability)**：好的函式名稱能讓人一眼看出這段程式碼的功能。
