### **核心概念：檔案就像程式的筆記本**

要和檔案互動，第一步當然是「開啟」它。Python 提供了一個內建函數 `open()` 來幫助我們。

#### 1. 開啟檔案 `open('檔名', '模式')`

`open()` 函數需要至少兩個參數：
*   **檔名 (File Path/Name)**：你想開啟或建立的檔案名稱（或包含路徑）。
*   **模式 (Mode)**：你打算如何使用這個檔案。

最常用的檔案模式有三種：

*   `'r'` (read)：**讀取**模式。用來讀取檔案的內容。如果檔案不存在，會報錯。
*   `'w'` (write)：**寫入**模式。用來寫入內容到檔案。
    *   **⚠️ 注意！** 如果檔案不存在，它會自動創建新檔案。
    *   **⚠️ 更重要！** 如果檔案已經存在，它會**清空原有的內容**，然後再寫入新的內容。所以使用 `w` 模式要小心！
*   `'a'` (append)：**追加**模式。用來在檔案的末尾追加內容。
    *   如果檔案不存在，它會自動創建新檔案。
    *   如果檔案存在，它會在原有內容的基礎上繼續寫入新內容，而不會覆蓋舊內容。

#### 2. 寫入檔案 `f.write()`

當你以 `'w'` 或 `'a'` 模式開啟檔案後，就可以使用檔案物件的 `write()` 方法將字串寫入檔案。記得，如果你想換行，需要自己加上 `\n` 這個換行符號喔！

#### 3. 讀取檔案 `f.read()` 或 `f.readline()` 或 `f.readlines()`

當你以 `'r'` 模式開啟檔案後，有幾種方法可以讀取內容：
*   `f.read()`：讀取整個檔案的所有內容，作為一個大字串返回。
*   `f.readline()`：讀取檔案的一行內容，作為一個字串返回。
*   `f.readlines()`：讀取檔案的所有行，將每一行作為一個字串存儲在一個列表中返回。

#### 4. **⚠️ 重要提醒：關閉檔案 `f.close()`**

無論你讀取還是寫入檔案，完成操作後都務必記得呼叫 `f.close()` 來關閉檔案！這就像你打開一本書看完了要記得闔上它一樣。不關閉檔案可能會導致以下問題：
*   資源洩漏：程式佔用系統資源，可能導致系統變慢。
*   資料不完整：寫入的資料可能沒有完全寫入磁碟，導致資料丟失。

### **實作環節：動手讓程式擁有記憶！**

我們來看看具體的程式碼範例吧！

#### 範例 1：寫入檔案（使用傳統 `open()` / `close()`）

```python
# 寫入檔案範例
print("--- 正在寫入檔案 (my_first_file.txt) ---")
file_path = "my_first_file.txt"

# 'w' 模式會創建新檔案，如果存在則清空
# encoding='utf-8' 是個好習慣，可以避免亂碼問題
f = open(file_path, 'w', encoding='utf-8')
f.write("哈囉，程式世界！\n")
f.write("這是我的第一個檔案寫入練習。\n")
f.write("希望你喜歡！\n")
f.close() # 記得關閉檔案！
print(f"檔案 '{file_path}' 已寫入完成。請檢查同資料夾下的檔案！")
```
執行這段程式碼後，你可以在你的程式碼文件所在的資料夾裡，找到一個名為 `my_first_file.txt` 的檔案，打開它，你會看到你寫入的內容！

#### 範例 2：讀取檔案（使用傳統 `open()` / `close()`）

```python
# 讀取檔案範例
print(f"\n--- 正在讀取檔案 ({file_path}) ---")
try:
    f = open(file_path, 'r', encoding='utf-8')
    content = f.read() # 讀取所有內容
    print("檔案內容如下：")
    print(content)
    f.close() # 記得關閉檔案！
    print(f"檔案 '{file_path}' 已讀取完成。")
except FileNotFoundError:
    print(f"錯誤：檔案 '{file_path}' 不存在，無法讀取。")
```
這裡我加了一個 `try-except` 區塊來處理檔案不存在的錯誤，這樣程式就不會直接崩潰，會更健壯！

#### 範例 3：檔案的「智能管家」：`with open(...) as f:` (**推薦使用！**)

現在，我要教你一個更優雅、更安全的方式來處理檔案，它被稱為「上下文管理器」(Context Manager)。使用 `with open(...) as f:` 語法，Python 會自動處理檔案的開啟和關閉，即使發生錯誤也不用擔心忘記關閉！這大大簡化了程式碼，也降低了出錯的風險。

```python
# 使用 with open 寫入檔案
print("\n--- 使用 with open 寫入檔案 (my_smart_file.txt) ---")
smart_file_path = "my_smart_file.txt"
with open(smart_file_path, 'w', encoding='utf-8') as f:
    f.write("這是使用 with open 寫入的內容。\n")
    f.write("它會自動幫我們關閉檔案，超方便！\n")
# 程式離開 with 區塊後，檔案會自動關閉
print(f"檔案 '{smart_file_path}' 已寫入完成。")

# 使用 with open 讀取檔案（逐行）
print(f"\n--- 使用 with open 讀取檔案 ({smart_file_path}) (逐行) ---")
with open(smart_file_path, 'r', encoding='utf-8') as f:
    print("檔案內容如下（逐行顯示）：")
    for line in f: # for 迴圈直接迭代檔案物件，高效讀取每一行
        print(line.strip()) # .strip() 可以移除每行末尾的換行符和多餘空格
print(f"檔案 '{smart_file_path}' 已讀取完成。")
```
看到沒？使用 `with` 語句就不用手動 `f.close()` 了，是不是很棒？以後處理檔案，盡量都用這個方法喔！

#### 範例 4：追加內容到檔案 (`'a'` 模式)

```python
# 追加內容到檔案 (my_append_file.txt)
print("\n--- 正在追加內容到檔案 (my_append_file.txt) ---")
append_file_path = "my_append_file.txt"

# 先寫入一些初始內容 (如果檔案不存在會創建，存在則清空)
with open(append_file_path, 'w', encoding='utf-8') as f:
    f.write("這是檔案的原始內容。\n")
print(f"檔案 '{append_file_path}' 初始內容已寫入。")

# 現在使用 'a' 模式追加內容
with open(append_file_path, 'a', encoding='utf-8') as f:
    f.write("這是新追加的內容。\n")
    f.write("它不會覆蓋舊內容喔！\n")
print(f"檔案 '{append_file_path}' 已追加完成。")

# 再次讀取確認
print(f"\n--- 讀取追加後的檔案 '{append_file_path}' ---")
with open(append_file_path, 'r', encoding='utf-8') as f:
    print(f.read())
```
執行這個範例，你會看到 `my_append_file.txt` 裡包含了原始內容和追加的內容，證明 `'a'` 模式確實是追加而不是覆蓋！
