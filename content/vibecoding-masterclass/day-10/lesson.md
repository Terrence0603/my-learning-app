### 一、 `for` 迴圈：當你「知道」要重複幾次時的最佳選擇！

首先，我們來認識一下 `for` 迴圈。它的出場時機通常是當你**「知道」需要重複執行多少次**，或是要**「遍歷」一個序列中的所有項目時**（像是列表中的每一個元素）。

想像你要點名班上所有同學，你知道有幾個人，一個一個點過去就好。或者，你要把一盒蘋果的每個蘋果都洗一遍。這就是 `for` 迴圈最擅長的工作！

在 Python 中，`for` 迴圈的語法是這樣的：

```python
for 變數 in 序列:
    # 在這裡寫下你想要重複執行的程式碼
    # 每次迴圈，「變數」會自動取得序列中的下一個項目
```

**程式碼範例 1：使用 `range()` 產生數字序列**

`range()` 是一個非常好用的函數，它會產生一個數字序列。`range(5)` 會從 0 開始，產生 0, 1, 2, 3, 4 這五個數字。

```python
print("--- For 迴圈範例 1: 使用 range() ---")
for i in range(5): # 從 0 數到 4，總共 5 次
    print(f"這是第 {i+1} 次打招呼！") # 這裡使用 f-string，讓輸出更動態
```

**輸出結果：**
```
--- For 迴圈範例 1: 使用 range() ---
這是第 1 次打招呼！
這是第 2 次打招呼！
這是第 3 次打招呼！
這是第 4 次打招呼！
這是第 5 次打招呼！
```

在這個例子中，`i` 這個變數會依序變成 `range(5)` 產生的每一個數字 (0, 1, 2, 3, 4)，然後程式碼區塊（也就是 `print()` 那一行）就會跟著執行 5 次。

**程式碼範例 2：遍歷列表 (List) 中的所有項目**

`for` 迴圈也非常適合用來處理列表、字串等集合型資料中的每一個元素。

```python
print("\n--- For 迴圈範例 2: 遍歷列表 ---")
水果們 = ["蘋果", "香蕉", "櫻桃", "芭樂"]

for 水果 in 水果們:
    print(f"我喜歡吃 {水果}。")
```

**輸出結果：**
```
--- For 迴圈範例 2: 遍歷列表 ---
我喜歡吃 蘋果。
我喜歡吃 香蕉。
我喜歡吃 櫻桃。
我喜歡吃 芭樂。
```

看到了嗎？`for` 迴圈自動幫我們把列表中的每個「水果」都拿出來，然後執行我們想對它做的動作。是不是很方便呢？

### 二、 `while` 迴圈：只要「條件成立」，我就一直做下去！

接下來是 `while` 迴圈。它比較像是「**只要某個條件成立，我就一直做下去，直到條件不再成立為止**」。

想想看，你要煮一鍋湯，你會一直攪拌，直到湯變濃稠為止，對吧？你不知道要攪拌幾下（不像 `for` 迴圈你明確知道有幾個蘋果），但你知道什麼時候要停。或者，你玩一個遊戲，只要你還沒贏，你就會一直玩下去。

在 Python 中，`while` 迴圈的語法是：

```python
while 條件:
    # 只要「條件」為 True，就一直重複執行這裡的程式碼
    # 記得要在迴圈內部想辦法讓條件有機會變成 False，否則會... (看下方警告！)
```

**程式碼範例 1：簡單計數**

```python
print("\n--- While 迴圈範例 1: 簡單計數 ---")
計數器 = 0 # 設定初始值

while 計數器 < 3: # 只要計數器小於 3，就繼續執行
    print(f"計數器現在是 {計數器}。")
    計數器 += 1 # 每次迴圈讓計數器加 1，這樣它才有機會達到 3，讓條件變成 False
```

**輸出結果：**
```
--- While 迴圈範例 1: 簡單計數 ---
計數器現在是 0。
計數器現在是 1。
計數器現在是 2。
```

這裡，當 `計數器` 變成 3 時，`計數器 < 3` 這個條件就會變成 `False`，迴圈就會停止。

**程式碼範例 2：處理使用者輸入（直到輸入正確為止）**

這是一個非常實用的 `while` 迴圈應用，常用於密碼驗證或資料輸入檢查。

```python
print("\n--- While 迴圈範例 2: 處理使用者輸入 ---")
密碼 = "" # 設定一個空字串作為初始值，確保條件為真以進入迴圈

while 密碼 != "python123": # 只要密碼不等於 "python123"，就繼續問
    密碼 = input("請輸入密碼：") # 從使用者那裡獲取輸入
    if 密碼 == "python123":
        print("密碼正確！歡迎進入。")
    else:
        print("密碼錯誤，請再試一次。")
print("程式執行完畢。")
```

**輸出結果範例：** (假設使用者第一次輸入 "abc"，第二次輸入 "python123")
```
--- While 迴圈範例 2: 處理使用者輸入 ---
請輸入密碼：abc
密碼錯誤，請再試一次。
請輸入密碼：python123
密碼正確！歡迎進入。
程式執行完畢。
```

在這個例子中，`while` 迴圈會一直執行，直到使用者輸入的密碼正確為止。

**🚨 特別注意！`while` 迴圈有個大陷阱叫做「無限迴圈」(Infinite Loop)！**

如果你不小心，讓 `while` 迴圈的條件**永遠都是 `True`**，那麼程式就會一直跑下去，永無止境！這會導致程式卡住，甚至耗盡電腦資源。

例如，如果你在範例 1 中，忘記寫 `計數器 += 1` 這一行，那麼 `計數器` 永遠都是 0，`0 < 3` 永遠是 `True`，程式就會一直印 `計數器現在是 0。`

**如何避免無限迴圈？**
務必確保你在 `while` 迴圈的內部，有辦法讓「條件」有一天會變成 `False`。

**如果不小心進入無限迴圈怎麼辦？**
別慌！在終端機或命令提示字元中，通常可以按下 **`Ctrl + C`** 來強制終止程式的執行。

### 三、 `for` vs. `while` 迴圈：何時使用？

簡單來說：
*   **`for` 迴圈**：當你**知道要重複「幾次」**，或要**遍歷「一個集合中的所有項目」**時，`for` 迴圈通常更簡潔、更直觀。
*   **`while` 迴圈**：當你**要重複執行「直到某個條件不成立」**時（你不知道具體要重複幾次），`while` 迴圈是你的好幫手。

雖然在某些情況下，兩者可以互相轉換，但選擇最適合的迴圈類型能讓你的程式碼更清晰易懂。
