### 【第 7 天：Part 3: Python 變數與資料型態】

#### 一、Python 變數：你的「資訊收納箱」

想像一下，你家裡有很多東西，像是書、衣服、零食。你會把它們放在不同的箱子或櫃子裡，並且在上面貼上標籤，對不對？例如：「我的書」、「冬天的衣服」、「追劇零食」。

在程式世界裡，變數就像是這些「貼著標籤的收納箱」。它們是用來**儲存資料**的。當我們需要記住一個名字、一個數字、或者某件事是不是真的時候，我們就會把它放進一個變數裡。

**為什麼需要變數？**

1.  **記憶資料：** 讓你的程式能記住各種資訊。
2.  **程式碼可讀性：** 比起一堆數字和文字，用有意義的變數名稱（例如 `user_name` 而不是 ` "Alice"`）更能讓人一眼看出程式在做什麼。
3.  **重複使用：** 如果一個值會被多次用到，把它存在變數裡，修改時只需要改一個地方，大大提高效率。

**如何建立變數？**

在 Python 中建立變數非常簡單，語法是：

```python
變數名稱 = 值
```

*   `變數名稱`：就是你給收納箱貼的標籤，用來辨識它。
*   `=`：這個符號叫做「賦值運算子」，它的意思是「把右邊的值存到左邊的變數裡」。
*   `值`：就是你要存入的實際資料。

讓我們來看幾個例子：

```python
# 範例 1: 建立變數並儲存不同的資訊

# 儲存一個名字 (文字)
my_name = "小明"

# 儲存一個年齡 (數字)
my_age = 30

# 儲存一個身高 (帶小數點的數字)
my_height = 175.5

# 儲存一個布林值 (判斷是否為學生)
is_student = True

# 現在，我們可以透過變數名稱來取出這些值
print(f"我的名字是：{my_name}")
print(f"我的年齡是：{my_age} 歲")
print(f"我的身高是：{my_height} 公分")
print(f"我是一個學生嗎？{is_student}")
```

**【小提醒】變數命名規則：**

*   變數名稱可以包含英文字母、數字和底線 (`_`)。
*   不能以數字開頭。
*   不能使用 Python 的保留字（例如 `print`, `if`, `for` 等）。
*   區分大小寫 (`name` 和 `Name` 是不同的變數)。
*   建議使用小寫字母和底線來增加可讀性 (例如 `first_name` 而不是 `FirstName`)。

#### 二、Python 資料型態：你的「資料種類」

好了，我們有了收納箱（變數），那收納箱裡面可以放哪些「種類」的資料呢？這就是「資料型態」要告訴我們的事。不同的資料型態有不同的特性和用法。

Python 會根據你賦予的值，自動判斷它的資料型態，這讓初學者非常方便！我們來看看幾個最常見的資料型態：

1.  **整數 (Integer, `int`)**
    *   用來儲存沒有小數點的**整數**，可以是正數、負數或零。
    *   範例：`10`, `-5`, `0`, `1000`

2.  **浮點數 (Floating-point number, `float`)**
    *   用來儲存**帶有小數點的數字**。
    *   範例：`3.14`, `-0.5`, `100.0` (即使是整數，只要有小數點就是 float)

3.  **字串 (String, `str`)**
    *   用來儲存**文字資料**。你必須用**單引號 (`'`) 或雙引號 (`"`)** 把文字包起來。
    *   範例：`"Hello World"`, `'Python 真有趣'`, `"123"` (數字用引號包起來就變成字串了！)

4.  **布林值 (Boolean, `bool`)**
    *   用來儲存**真 (True) 或假 (False)** 這兩種狀態。注意 `True` 和 `False` 的第一個字母要大寫。
    *   範例：`True` (表示真、是、開啟), `False` (表示假、否、關閉)

**如何知道變數的資料型態？**

Python 提供了一個內建函數 `type()`，可以讓你檢查任何變數或值的資料型態。

```python
# 範例 2: 認識常見的資料型態並檢查它們

product_name = "Python 學習套件" # 這是一個字串
product_price = 1999              # 這是一個整數
discount_rate = 0.15              # 這是一個浮點數
has_stock = True                  # 這是一個布林值
product_code = "PY-001"           # 這也是一個字串 (即使有數字，但被引號包圍)

print(f"變數 product_name 的型態是：{type(product_name)}")
print(f"變數 product_price 的型態是：{type(product_price)}")
print(f"變數 discount_rate 的型態是：{type(discount_rate)}")
print(f"變數 has_stock 的型態是：{type(has_stock)}")
print(f"變數 product_code 的型態是：{type(product_code)}")
```

你會看到輸出類似 `<class 'str'>`、`<class 'int'>` 等等，這就告訴你變數的具體型態。

#### 三、綜合練習：讓你的程式開始有記憶！

現在，讓我們把變數和資料型態，搭配之前學過的 `print()` 函數和 f-string 一起玩玩看！

```python
# 範例 3: 用變數來描述一個虛擬人物

# 定義人物的基本資訊
character_name = "艾絲黛拉"
character_age = 22
character_occupation = "魔法師"
character_hp = 100.0 # 生命值，可能有小數點
character_mana = 75  # 魔力值，通常是整數
is_hero = True       # 是否為主角？

# 利用 f-string 和變數來印出人物介紹
print("--- 人物檔案 ---")
print(f"姓名：{character_name}")
print(f"年齡：{character_age} 歲")
print(f"職業：{character_occupation}")
print(f"生命值 (HP)：{character_hp}")
print(f"魔力值 (Mana)：{character_mana}")
print(f"是否為主角：{is_hero}")
print("---------------")

# 假設人物年齡增長，或生命值有變化，變數可以很方便地更新
character_age = character_age + 1 # 年齡加一歲
character_hp = character_hp - 10.5 # 受到傷害，HP減少

print(f"\n一年後，{character_name} 的年齡變成：{character_age} 歲")
print(f"經過戰鬥，{character_name} 的 HP 剩下：{character_hp}")
```
