### 一、 了解「限制條件」(Constraints)

想像一下，你正在設計一個遊戲。遊戲規則會說：「玩家的血量不能低於 0」或是「角色等級最高 100 級」。這些就是「限制條件」。

在程式世界裡，限制條件指的是你為資料或行為設定的規則。它們確保你的程式能正確運行，並處理那些「不預期」的情況。為什麼這很重要呢？

1.  **確保程式正確性**：例如，一個計算學生平均分數的程式，分數不能是負數或大於 100。
2.  **提升使用者體驗**：如果使用者輸入了錯誤的資料，程式可以禮貌地告訴他們，而不是直接崩潰。
3.  **防止潛在錯誤**：限制條件就像是程式的「安全網」，避免你的程式出現奇怪的行為。

我們最常用的方式就是 `if`...`else` 語句，來檢查這些條件。

#### 程式碼範例：簡單的年齡限制

假設我們想寫一個程式，詢問使用者的年齡，但我們知道年齡不應該是負數。

```python
print("歡迎使用年齡檢查器！")
age_str = input("請輸入您的年齡：") # 使用 input 接收使用者輸入，它會以字串形式返回

try:
    # 嘗試將輸入的字串轉換為整數 (數字)
    age = int(age_str)

    # 設定第一個限制條件：年齡必須大於 0
    if age > 0:
        print(f"您的年齡是 {age} 歲，很棒！") # f-string 讓輸出更方便
    else:
        print("哎呀，年齡必須是正數喔！請再檢查一下。")

except ValueError:
    # 如果使用者輸入的不是數字 (例如輸入了文字 "abc")，int() 會報錯 ValueError
    print("輸入錯誤！請輸入一個有效的數字。")

print("感謝您的配合！")
```

**程式碼解釋：**

*   `input()` 函數會暫停程式，等待你輸入內容。
*   `try...except ValueError` 是一個錯誤處理機制。它會「嘗試」執行 `try` 區塊裡的程式碼，如果發生 `ValueError` (例如，想把「哈囉」轉成數字)，就會跳到 `except` 區塊執行錯誤提示，而不是讓程式直接崩潰。這是一種很重要的「限制條件」處理方式！
*   `if age > 0:` 就是我們設定的限制條件。如果條件為真，就執行 `if` 下方的程式碼；否則，執行 `else` 下方的程式碼。

### 二、 迭代精進的「對話技巧」(Iterative Refinement Skills)

現在，我們來聊聊另一個超級實用，但常常被忽略的技能：「迭代精進」。什麼意思呢？

它就是「**一步一步地改進你的程式，而不是想一次做到完美**」。

想像你正在畫一幅畫。你不會一開始就畫出所有細節，對吧？你可能會先畫出大致的輪廓，然後慢慢加上顏色、陰影，最後才處理細節。寫程式也是一樣！

「迭代對話技巧」指的就是你在寫程式時，不斷地問自己：「這個程式現在能跑嗎？」「它還少了什麼？」「如果使用者做了這個，會怎樣？」「我可以怎麼讓它更好一點？」—— 這種和自己程式的「對話」就是精進的過程。

#### 為什麼迭代精進很重要？

1.  **降低難度**：把大問題拆解成小問題，每個小問題都更容易解決。
2.  **更快看到成果**：即使是很小的功能，只要能跑動，就會給你帶來成就感，讓你更有動力。
3.  **更容易除錯 (Debug)**：每次只增加一點點功能，如果出錯了，你就能很快知道是哪一部分導致的問題。

現在，我們來看看如何用「迭代精進」的方式，改善我們剛才的年齡檢查器。你可能會發現，如果使用者輸入錯誤，程式就結束了，這不太好。我們希望它能一直詢問，直到得到正確的年齡為止！

#### 程式碼範例：結合限制條件與迭代精進

```python
print("歡迎使用年齡檢查器 2.0！")

# 我們用一個變數來標記是否得到了有效的年齡，初始設定為 False (沒有得到)
is_valid_age = False
age = 0 # 宣告 age 變數，以便在迴圈外也能使用

# 只要 is_valid_age 是 False，就一直執行迴圈 (迭代)
while not is_valid_age:
    age_str = input("請輸入您的年齡：")

    try:
        age = int(age_str)

        # 運用限制條件 1：年齡必須大於 0
        # 運用限制條件 2：年齡也應該在一個合理的範圍內 (例如不超過 120 歲)
        if 0 < age < 120: # 簡潔的寫法，表示 age 大於 0 且小於 120
            print(f"您的年齡是 {age} 歲，資料已成功接收！")
            is_valid_age = True # 年齡有效了，設定為 True，下次迴圈就不會再執行
        elif age <= 0:
            print("哎呀，年齡必須是正數喔！請再試一次。")
        else: # age >= 120
            print("抱歉，請輸入一個更合理的年齡 (通常不超過 120 歲)。")

    except ValueError:
        print("輸入錯誤！請輸入一個有效的數字。")

print(f"感謝您的輸入。您的有效年齡是：{age}。程式結束。")
```

**程式碼解釋：**

*   `while not is_valid_age:` 這是一個 `while` 迴圈。只要 `is_valid_age` 這個變數是 `False`，迴圈裡面的程式碼就會一直重複執行。這就是我們的「迭代」部分！
*   當使用者輸入了一個符合所有限制條件的年齡（大於 0 且小於 120），我們就將 `is_valid_age` 設定為 `True`。這樣，`while` 迴圈的條件 `not is_valid_age` 就會變成 `False`，迴圈就會停止。
*   你看，我們不僅使用了 `if...else` 來處理限制條件，還用 `while` 迴圈來不斷「迭代」詢問，直到滿足條件為止。這就是限制條件與迭代精進的最佳搭檔！

### 總結與期待

今天的課程我們學到了兩個讓程式更強大的思考方式：
