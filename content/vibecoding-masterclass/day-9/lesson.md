### **核心概念：`if` 語句 (如果...就...)**

最基本的判斷，就是『如果...就...』。當某個**條件成立**時，我們就執行某段特定的程式碼。

它的基本語法長這樣（這裡我們用類似 Python 的寫法，因為它很直觀）：

```python
if (條件成立):
    # 如果條件是 true (真)，就執行這段程式碼
    # 注意這裡有縮排！這是告訴電腦這段程式碼屬於 if 判斷
```

**判斷的關鍵在於『條件』**，它會是一個結果為 `true` (真) 或 `false` (假) 的表達式。例如：`你的分數 > 60`、`今天是假日`、`燈是開著的`。

#### **範例 1: 簡單的 `if` 判斷**

假設我們想讓程式判斷車速是否超速：

```python
# 範例 1: 簡單的 if 判斷
current_speed = 70      # 假設目前車速是 70
speed_limit = 60        # 假設速限是 60

print(f"目前車速是 {current_speed} km/h")

if (current_speed > speed_limit):
    # 如果 current_speed 大於 speed_limit (條件為 true)，就執行這裡
    print("你超速了！請減速。")

print("車速檢查完畢。") # 這行無論如何都會執行
```

**執行看看：**
你會看到 `你超速了！請減速。` 和 `車速檢查完畢。`。
如果把 `current_speed` 改成 `50`，那麼 `current_speed > speed_limit` 這個條件就是 `false`，所以 `print("你超速了！請減速。")` 這行程式碼就會被跳過，只會印出 `車速檢查完畢。`。

是不是很神奇？你的程式已經會根據狀況做選擇了！

### **進階判斷：`if...else` 語句 (如果...否則...)**

光有『如果就』還不夠，我們通常也會想知道『如果不是這樣，那該怎麼辦？』這時候，`else` 就派上用場了！

它的基本語法：

```python
if (條件成立):
    # 如果條件是 true (真)，就執行這段程式碼 A
else:
    # 否則 (如果條件是 false (假))，就執行這段程式碼 B
```

#### **範例 2: `if...else` 判斷**

讓我們來判斷天氣是否熱到需要開冷氣：

```python
# 範例 2: if...else 判斷
temperature = 28 # 假設目前氣溫是 28 度

print(f"目前氣溫是 {temperature} 度。")

if (temperature > 25): # 如果氣溫大於 25 度
    print("天氣有點熱，開冷氣吧！")
else: # 否則 (氣溫小於或等於 25 度)
    print("氣溫舒適，不用開冷氣。")

print("溫度檢查結束。")
```

**執行看看：**
因為 `28 > 25` 是 `true`，所以會印出 `天氣有點熱，開冷氣吧！`。
如果把 `temperature` 改成 `20`，那麼 `20 > 25` 是 `false`，程式就會跳到 `else` 區塊，印出 `氣溫舒適，不用開冷氣。`。
你的程式現在是不是更貼心了呢？

### **多重判斷：`if...else if...else` 語句 (如果...或者如果...否則...)**

有時候，一個條件不夠，我們需要判斷多種情況，並依序給出不同的回應。這時候，我們可以使用 `else if` (在許多程式語言中會寫成 `elif`)。

它的基本語法：

```python
if (條件 1 成立):
    # 如果條件 1 是 true (真)，執行這段程式碼 A
elif (條件 2 成立): # 只有在條件 1 不成立的前提下，才會判斷條件 2
    # 如果條件 2 是 true (真)，執行這段程式碼 B
elif (條件 3 成立): # 只有在條件 1 和 2 都不成立的前提下，才會判斷條件 3
    # 如果條件 3 是 true (真)，執行這段程式碼 C
else: # 如果以上所有條件都不成立，就執行這段程式碼 D
    # ...
```

**重要觀念：** 這些條件是**依序判斷**的，只要有一個條件為 `true`，該區塊的程式碼就會被執行，然後整個 `if/elif/else` 結構就會結束，不會再檢查後面的條件了。

#### **範例 3: `if...elif...else` 多重判斷**

讓我們來寫一個程式，根據分數給出不同的評語：

```python
# 範例 3: if...elif...else 多重判斷
score = 75 # 假設你的考試分數是 75 分

print(f"你的分數是 {score} 分。")

if (score >= 90):
    print("恭喜你，獲得 A 等級！ 🎉")
elif (score >= 80): # 只有在 score < 90 的前提下，才會判斷這裡
    print("表現不錯，獲得 B 等級！ 👍")
elif (score >= 60): # 只有在 score < 80 的前提下，才會判斷這裡
    print("及格了，獲得 C 等級！ 👏")
else: # 如果以上所有條件都不成立 (分數低於 60)
    print("這次沒過，下次再努力！ 💪")

print("評分完畢。")
```

**執行看看：**
因為 `score` 是 `75`：
1.  `score >= 90` (75 >= 90) 是 `false`。
2.  所以繼續判斷下一個 `elif`：`score >= 80` (75 >= 80) 是 `false`。
3.  再判斷下一個 `elif`：`score >= 60` (75 >= 60) 是 `true`！
4.  所以會執行 `print("及格了，獲得 C 等級！ 👏")`。
5.  然後整個 `if/elif/else` 結構結束，跳過 `else` 部分，直接執行 `print("評分完畢。")`。

如果你的分數是 `95`，它會直接判斷第一個 `if` 為 `true`，然後印出 `A 等級`，後面的 `elif` 和 `else` 就不會再被考慮了。

### **一些小提醒 (讓程式碼更專業！)**

1.  **縮排 (Indentation):** 你可能已經注意到了，`if`、`elif`、`else` 後面的程式碼都需要**縮排**。這是程式碼的『禮儀』，也決定了哪些程式碼屬於哪個判斷區塊。在 Python 中，縮排是語法的一部分，錯誤的縮排會導致錯誤！
2.  **比較運算子:** 在條件中，我們使用了 `>` (大於)、`>=` (大於等於)。其他常用的比較運算子還有：
    *   `==` (等於，注意是兩個等號，一個等號 `=` 是賦值)
    *   `!=` (不等於)
    *   `<` (小於)
    *   `<=` (小於等於)
3.  **邏輯運算子:** 未來你還會遇到 `and` (且)、`or` (或)、`not` (非)，它們能讓你組合更複雜的條件。例如：`if (age > 18 and is_student):`。
