---

#### 一、什麼是「系統指令」？ (System Instructions)

想像一下，你是一家高檔餐廳的經理。在顧客點餐之前，你不會讓服務生隨便亂來吧？你會有一套「員工訓練手冊」，告訴他們：

*   「永遠要禮貌地問候顧客。」
*   「上菜時要小心，並介紹菜品。」
*   「回答問題時要清晰、簡潔。」
*   「遇到投訴時，請立即通知主管。」

這些就是「系統指令」！它們不是直接回答客戶的問題，而是**設定整個服務的基調、行為規範和基本原則**。對AI來說，系統指令就是告訴它：「在你回答任何問題之前，請先遵守這些基本規則！」

它的目的通常是：
*   **保持一致性：** 讓AI的回覆風格、格式始終如一。
*   **確保安全與倫理：** 避免生成不適當的內容。
*   **定義整體行為：** 例如，是像一個幽默的朋友，還是一個嚴謹的學術顧問。

---

#### 二、什麼是「角色設定」？ (Role Setting)

延續餐廳的比喻。當客人點了餐，服務生需要知道他現在是「上菜員」，還是「調酒師」，或是「點餐員」。不同的角色有不同的職責和知識。

對AI來說，「角色設定」就是明確告訴它：「你現在扮演的是誰？你的專業是什麼？」

當你設定一個角色時，你是在**賦予AI一個特定的身份、專業領域和思維模式**。這會極大地影響它回答問題的內容、深度和語氣。

例如：
*   「你是一位資深的 Python 開發者。」
*   「你是一位友善的國小科學老師。」
*   「你是一位嚴謹的法律顧問。」

設定角色能讓AI集中在特定的知識領域，並以該角色的視角來思考和回應，提供更專業、更貼切的答案。

---

#### 三、為什麼它們如此重要？

結合「系統指令」和「角色設定」，就像是給你的AI伙伴一張「超級詳細的任務簡報」！它不僅知道自己是誰 (角色)，也知道該怎麼表現 (系統指令)。這樣一來，它就能給你：

1.  **更精準的回覆：** 直接命中你的需求。
2.  **更一致的風格：** 不會一下子嚴肅，一下子又輕鬆。
3.  **更高效率的互動：** 減少來回澄清的時間。

#### 四、程式碼範例：如何使用它們？

在實際應用中，尤其是在透過程式碼與大型語言模型 (LLM) 互動時，我們會有明確的地方來設置這些訊息。而在日常的聊天機器人介面中，你通常會將這些指令放在你的第一條訊息中。

##### 範例 1: 在聊天介面中的應用 (概念性)

即使沒有獨立的「系統指令」欄位，你也可以透過你的提問來「暗示」或「設定」AI的角色和行為。

```markdown
# 範例提示 1: 設定程式導師角色

**你的提問:**
你是一位專業的程式導師，專門為初學者提供清晰、簡潔的解釋。
請用最簡單的語言和一個具體的程式碼範例，解釋什麼是『變數』。
請確保你的語氣保持輕鬆和鼓勵。

---

**AI 可能的回覆 (模擬):**
太棒了！未來的程式設計師們，很高興能帶你探索變數這個超級重要的概念！

想像一下，**變數 (Variable)** 就像是一個你可以在裡面「暫時儲存東西」的盒子。每個盒子都有一個獨特的名字，這樣你就能找到它。你可以把數字、文字或其他資訊放進這個盒子裡。當你需要這些資訊的時候，就呼叫盒子的名字，裡面的東西就會跑出來給你用！

在 Python 裡，變數的使用非常簡單：

```python
# 這是一個名為 'my_age' 的盒子，裡面裝著數字 25
my_age = 25

# 這是一個名為 'my_name' 的盒子，裡面裝著文字 "小明"
my_name = "小明"

# 現在我們來看看盒子裡裝了什麼
print(my_age)   # 輸出: 25
print(my_name)  # 輸出: 小明

# 你甚至可以改變盒子裡的東西！
my_age = 26
print(my_age)   # 輸出: 26 (現在盒子裡是 26 了！)
```

看到沒？`my_age` 和 `my_name` 就是變數的「名字」，而 `=` 號就是把東西「放進去」的動作。是不是很有趣呢？別擔心，多練習幾次你就上手了！
```

##### 範例 2: 透過程式碼 API 呼叫 (更明確的系統指令)

當你使用 Python 或其他語言程式化地呼叫 LLM API 時 (例如 OpenAI 的 API)，通常會有一個明確的 `system` 角色，讓你設定這些指令。

```python
# 假設我們有一個與LLM互動的簡單函數 (這是一個高度簡化的模擬)
def chat_with_llm(system_message, user_message):
    print(f"\n--- 正在向 LLM 發送指令 ---")
    print(f"系統設定 (AI的幕後身份): '{system_message}'")
    print(f"你的提問 (使用者訊息): '{user_message}'")
    print(f"--- 接收 LLM 回覆 (模擬) ---")
    
    # 這裡會是實際呼叫 LLM API 並獲得回覆的邏輯
    # 為了教學目的，我們模擬一個簡單的回覆
    if "專業的程式導師" in system_message and "迴圈" in user_message:
        return "好的，初學者們！迴圈就像是重複做一件事的小精靈。例如 Python 的 `for` 迴圈..."
    elif "資深Python開發者" in system_message and "最佳化" in user_message:
        return "當然，對於大型資料集，你可以考慮使用 NumPy 的向量化操作，這會比純 Python 迴圈快上許多..."
    else:
        return "我已經接收到您的指令和問題，並準備好為您服務！"

# 範例 A: 設定 AI 為「專業的程式導師」
system_instruction_A = "你是一位專業的程式導師，專門為初學者提供清晰、簡潔的解釋。你的語氣應保持輕鬆和鼓勵。"
user_query_A = "請用一個簡單的例子解釋什麼是『迴圈』。"

response_A = chat_with_llm(system_instruction_A, user_query_A)
print(f"AI 的模擬回覆: {response_A}")

# 範例 B: 設定 AI 為「資深的 Python 開發者」，並要求提供高效能建議
system_instruction_B = "你是一位資深Python開發者，對於撰寫高效能、乾淨的程式碼有豐富經驗。請直接給出程式碼範例並解釋其優勢。"
user_query_B = "當處理大量資料時，如何最佳化 Python 的迴圈？"

response_B = chat_with_llm(system_instruction_B, user_query_B)
print(f"AI 的模擬回覆: {response_B}")
```

從上面的範例中，你可以看到：
*   在範例 A 中，AI 應該會以導師的輕鬆語氣來解釋迴圈。
*   在範例 B 中，AI 會變身為資深開發者，用更專業的術語和方法來討論程式碼最佳化。

#### 小提示與練習：

1.  **具體明確：** 你的系統指令和角色設定越具體，AI 的表現就會越好。
2.  **不斷嘗試：** 多試試看不同的角色，例如「美食家」、「旅行規劃師」、「哲學家」等，看看 AI 會怎麼回應。
3.  **疊加組合：** 你可以同時設定多個指令和角色，例如：「你是一位幽默的歷史老師，請用說故事的方式解釋二戰的起因，並確保內容簡短易懂。」
