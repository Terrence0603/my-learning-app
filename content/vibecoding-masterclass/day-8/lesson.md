## 🎯 主題：運算與格式化輸出

### 一、 數字的魔法：基本運算 (Arithmetic Operations)

電腦最擅長的事情之一就是數字運算。Python 提供了非常直觀的符號來執行各種數學操作。

讓我們來看看這些「運算符號」：

| 運算子 | 意義       | 範例     | 結果 |
| :----- | :--------- | :------- | :--- |
| `+`    | 加法       | `5 + 3`  | `8`  |
| `-`    | 減法       | `10 - 4` | `6`  |
| `*`    | 乘法       | `7 * 2`  | `14` |
| `/`    | 除法       | `10 / 3` | `3.333...` (浮點數結果) |
| `//`   | 整數除法   | `10 // 3`| `3`  (只取整數部分) |
| `%`    | 取餘數     | `10 % 3` | `1`  (10 除以 3 餘 1) |
| `**`   | 乘方       | `2 ** 3` | `8`  (2 的 3 次方) |

**小提醒：**
*   ` / ` 除法運算，結果**永遠**是浮點數 (帶有小數點的數字)。
*   ` // ` 整數除法，會將小數點後的部分**直接捨去**，只保留整數。
*   ` % ` 取餘數，在判斷奇偶數、循環、分組等情境非常有用！

#### 💡 程式碼範例：簡單的數字計算

```python
print("--- 數字運算小試身手 ---")

# 假設你買了 3 顆蘋果，每顆 15 元；5 顆橘子，每顆 10 元。
apples_price = 15
apples_count = 3

oranges_price = 10
oranges_count = 5

# 計算蘋果的總價
total_apples_cost = apples_price * apples_count
print(f"蘋果總價：{total_apples_cost} 元")

# 計算橘子的總價
total_oranges_cost = oranges_price * oranges_count
print(f"橘子總價：{total_oranges_cost} 元")

# 計算總共花了多少錢
total_cost = total_apples_cost + total_oranges_cost
print(f"總共花費：{total_cost} 元")

# 假設你有 50 元，可以買幾顆蘋果？會剩下多少錢？
my_money = 50
how_many_apples = my_money // apples_price
money_left = my_money % apples_price

print(f"我有 {my_money} 元，可以買 {how_many_apples} 顆蘋果，還剩下 {money_left} 元。")

# 你的身高是 1.75 公尺，體重 70 公斤。計算 BMI (體重(kg) / 身高(m) 的平方)
height = 1.75
weight = 70
bmi = weight / (height ** 2) # 這裡要注意括號，確保先算身高平方
print(f"你的 BMI 是：{bmi}")
```

看到沒？只用簡單的符號，我們就能讓程式幫我們完成各種計算！

#### 運算順序：誰先誰後？

跟數學一樣，Python 也有運算符號的優先順序：
1.  **括號 `()`**：永遠是老大，括號裡的先算。
2.  **乘方 `**`**
3.  **乘法 `*`、除法 `/`、整數除法 `//`、取餘數 `%`** (同級，由左至右)
4.  **加法 `+`、減法 `-`** (同級，由左至右)

當你不確定時，**使用括號 `()` 總是最好的選擇**，它能讓你的程式碼更清晰易懂，也能確保運算結果符合你的預期！

### 二、 讓輸出更美觀：格式化輸出 (Formatted Output)

我們已經能進行各種計算了，但如果輸出的結果只是單純的數字或字串，有時候會顯得有點生硬，不夠「人性化」。這時候，就需要「格式化輸出」的技巧了！

想像一下，你要跟朋友報告天氣：
*   **普通輸出：** `今天25.5度晴朗`
*   **格式化輸出：** `今天天氣晴朗，氣溫攝氏 25.5 度！`

是不是第二種聽起來舒服多了？在 Python 中，我們有幾種方式可以做到這點，最現代也最推薦初學者使用的方法，就是 **f-string (格式化字串文字)**。

#### 1. 最簡單的方式：使用 `print()` 內建的逗號 `,`

`print()` 函數非常聰明，當你用逗號分隔多個項目時，它會自動在這些項目之間加上一個空格，並且幫你把所有東西都轉成字串。

```python
print("--- 逗號分隔輸出 ---")
item = "麵包"
quantity = 2
price = 45.5

print("我買了", quantity, "個", item, "，每個", price, "元。")
# 輸出：我買了 2 個 麵包 ，每個 45.5 元。
```
雖然方便，但空格的位置是固定的，靈活度不高。

#### 2. 最推薦的方式：f-strings (格式化字串文字) ✨

f-string 是 Python 3.6 之後引入的強大功能，它讓字串格式化變得非常直觀、簡潔。你只需要在字串前面加上一個 `f` 或 `F`，然後在字串內部用大括號 `{}` 把變數或表達式包起來，Python 就會自動幫你替換掉！

```python
print("\n--- f-string 讓輸出更漂亮 ---")

item = "牛奶"
quantity = 1
price = 60.0

# 直接將變數嵌入字串中
print(f"我買了 {quantity} 瓶 {item}，一瓶 {price} 元。")

# f-string 甚至可以直接執行運算！
total_cost = quantity * price
print(f"總共花費：{total_cost} 元。")
print(f"喔對了，一年有 {365 * 24} 小時呢！") # 直接在 {} 中進行運算
```

**f-string 的進階魔法：控制數字顯示格式**

f-string 還能讓你精確控制數字的顯示方式，這在處理貨幣、百分比等數據時非常有用！

| 格式符號 | 意義                               | 範例                               | 結果       |
| :------- | :--------------------------------- | :--------------------------------- | :--------- |
| `:.2f`   | 浮點數，小數點後顯示 2 位           | `f"{value:.2f}"` (value=12.345)     | `12.35`    |
| `:,.0f`  | 浮點數，不顯示小數點，用逗號分隔千位 | `f"{value:,.0f}"` (value=1234567.89)| `1,234,568`|
| `:.0%`   | 顯示為百分比，不帶小數點           | `f"{rate:.0%}"` (rate=0.75)         | `75%`      |

#### 💡 程式碼範例：結合運算與 f-string 格式化輸出

```python
print("\n--- 結合運算與 f-string 實例 ---")

# 假設你銷售一個產品，需要計算利潤和銷售額
product_name = "AI 學習課程"
cost_price = 850.75      # 成本價
sell_price = 1299.99     # 銷售價
quantity_sold = 50       # 售出數量
tax_rate = 0.05          # 稅率 5%

# 計算單個產品利潤
profit_per_unit = sell_price - cost_price

# 計算總銷售額 (未稅)
total_revenue = sell_price * quantity_sold

# 計算總稅金
total_tax = total_revenue * tax_rate

# 計算最終總利潤
total_profit = (sell_price * quantity_sold) - (cost_price * quantity_sold) - total_tax

# 現在，用 f-string 把這些結果美觀地印出來！
print(f"產品名稱：{product_name}")
print(f"單個產品成本：NT$ {cost_price:.2f}") # 小數點後兩位
print(f"單個產品售價：NT$ {sell_price:.2f}") # 小數點後兩位
print(f"單個產品利潤：NT$ {profit_per_unit:.2f}") # 小數點後兩位

print(f"\n--- 銷售報告 ---")
print(f"售出數量：{quantity_sold} 個")
print(f"總銷售額 (未稅)：NT$ {total_revenue:,.2f}") # 加上千分位逗號，小數點後兩位
print(f"適用稅率：{tax_rate:.1%}") # 顯示為百分比，小數點後一位
print(f"應繳稅金：NT$ {total_tax:,.2f}") # 加上千分位逗號，小數點後兩位
print(f"最終總利潤：NT$ {total_profit:,.2f}") # 加上千分位逗號，小數點後兩位

# 檢查利潤是否為正數
if total_profit > 0:
    print("恭喜！這是一個獲利的產品！🎉")
else:
    print("需要檢討成本或定價策略了！🤔")
```
看到這些格式化後的數字，是不是報告起來更有感覺了呢？這就是 f-string 的魅力！
