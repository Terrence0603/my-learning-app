### 【第 1 天：AI 提示詞基礎與變數】

#### 🚀 你的第一個魔法咒語：AI 提示詞 (Prompts)

想像一下，你要跟一個超級聰明，但有點聽不懂「人話」的機器人溝通。你要怎麼告訴它你想要什麼呢？這時候，你就需要用到「提示詞」(Prompt)。

**什麼是提示詞？**
簡單來說，提示詞就是你給 AI 的**指令、問題或情境描述**。一個好的提示詞，就像一份清晰的食譜，能讓廚師（AI）做出你想要的美味料理。反之，模糊不清的提示詞，可能會讓 AI 做出一些你意想不到的東西喔！

**為什麼提示詞很重要？**
因為 AI 的輸出品質，很大程度上取決於你輸入的提示詞品質。越具體、越清楚、越有結構的提示詞，AI 就能給你越精準、越有用的回應。

**舉個例子：**

*   **壞的提示詞：** "寫點東西。" (AI 會很困惑：寫什麼？給誰看？什麼風格？)
*   **好的提示詞：** "請扮演一位友善的英文老師，用簡單的句子解釋『光合作用』給一個十歲小孩聽，並附上一個生活中的例子。" (是不是很明確？AI 知道它的角色、對象、內容和呈現方式。)

現在你已經對提示詞有了初步的概念。但如果我們希望這些提示詞能根據不同情況自動變化呢？這就需要用到今天的另一個主角：**變數**！

#### 📦 資訊的百寶箱：變數 (Variables)

在程式設計中，「變數」就像是一個貼有標籤的盒子，裡面可以裝各種資訊，例如文字、數字等等。你可以隨時打開盒子，看看裡面裝了什麼，也可以把裡面的東西換掉。

**為什麼需要變數？**
1.  **儲存資訊：** 你可以把用戶的名字、年齡、喜歡的顏色等資訊暫時存起來。
2.  **重複使用：** 一旦資訊儲存為變數，你就可以在程式的不同地方多次使用它，而不需要重複輸入。
3.  **彈性變化：** 當資訊需要更新時，你只需要修改變數的值，所有使用到這個變數的地方都會自動更新，讓你的程式變得更靈活。

**在 Python 中使用變數：**

Python 建立變數非常簡單，你只需要給它一個名字，然後用等號 `=` 把值賦予它。

```python
# 宣告並賦值變數 (想像你在貼標籤，把資訊放進盒子)

# 字串 (文字型態的資訊，要用引號 ' 或 " 包起來)
user_name = "小明"
favorite_subject = "程式設計"

# 整數 (數字型態的資訊，不用引號)
user_age = 12
score = 95

# 浮點數 (帶有小數點的數字)
pi_value = 3.14159

# 印出變數的值 (打開盒子看看裡面是什麼)
print(f"使用者姓名：{user_name}")
print(f"年齡：{user_age}歲")
print(f"最喜歡的科目：{favorite_subject}")
print(f"圓周率：{pi_value}")

# 你可以隨時改變變數的值
user_name = "小華"
print(f"新的使用者姓名：{user_name}")
```

**程式碼說明：**
*   `user_name = "小明"`：我們創建了一個名為 `user_name` 的變數，並把文字 "小明" 存進去。
*   `print()`：這是一個 Python 的內建函數，用來把括號裡面的內容顯示在螢幕上。
*   `f"文字 {變數} 文字"`：這是 Python 中一種很方便的「f-string」用法，可以直接把變數的值嵌入到字串裡面，是不是很酷？我們稍後會多加利用它！

#### ✨ 結合 AI 提示詞與變數：讓你的咒語動起來！

現在，我們要把提示詞和變數結合起來，讓你的 AI 提示詞不再是死板的，而是可以根據不同情況動態生成的。這正是程式設計的魅力之一！

我們可以使用上面提到的 **f-string** 功能，輕鬆地將變數嵌入到提示詞中。

```python
# 我們的變數，這些值可以來自用戶輸入，或者程式的其他部分
user_role = "資料科學家"
subject = "機器學習"
explanation_level = "初學者"
example_type = "生活實例"

# 使用 f-string 建立動態提示詞
# 注意看 { } 裡面的就是我們的變數名稱
ai_prompt_template = f"請扮演一位{user_role}，用深入淺出的方式，為一個{explanation_level}解釋{subject}的核心概念，並舉一個{example_type}。"

# 印出完整的提示詞，看看它長什麼樣子
print("--- 第一個動態提示詞 ---")
print(ai_prompt_template)

print("\n--- 變更變數後，提示詞會自動更新！---")
# 想像如果我們改變了這些變數的值
user_role = "歷史老師"
subject = "文藝復興"
explanation_level = "高中生"
example_type = "歷史事件"

# 再次生成提示詞，你會發現內容完全不同了！
ai_prompt_new = f"請扮演一位{user_role}，用深入淺出的方式，為一個{explanation_level}解釋{subject}的核心概念，並舉一個{example_type}。"
print(ai_prompt_new)
```

**是不是很神奇？** 透過變數，我們只需要定義一個提示詞的「模板」，然後根據不同的需求，改變變數的值，就可以輕鬆生成無數個不同的提示詞！這就是程式設計帶來的強大彈性。
