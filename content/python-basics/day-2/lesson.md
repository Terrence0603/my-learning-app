### 📦 第一站：變數 — 你的程式碼記憶盒子

想像一下，你在整理一個倉庫。你不會把所有東西都亂扔一通，對吧？你會用箱子把物品分門別類裝好，然後在箱子上貼上標籤，寫著「文件」、「工具」或是「餅乾」。這樣一來，下次你要找東西時，就能很快找到。

在程式設計中，『變數』就像是這些貼了標籤的箱子，可以用來『儲存』各種資訊，例如數字、文字、甚至是更複雜的資料。

**為什麼要用變數呢？**

1.  **儲存資料：** 你可以把計算結果、使用者輸入的資料、或任何你需要暫時記住的資訊存起來。
2.  **重複使用：** 一旦資料存入變數，你就可以在程式碼的不同地方多次使用它，而不需要重複輸入。
3.  **讓程式碼更清晰：** 給變數一個有意義的名字，你的程式碼就會像說故事一樣，容易閱讀和理解。

**如何在 Python 中創造變數？**

在 Python 中，創造一個變數非常簡單，就是給它一個名字，然後用等號 `=` 把值放進去。

```python
# 這是我的第一個變數！
my_favorite_number = 7

# 然後我印出它的值
print(my_favorite_number)
```

**變數名稱的小規矩：**

*   只能包含英文字母 (a-z, A-Z)、數字 (0-9) 和底線 `_`。
*   不能以數字開頭 (例如 `1name` 是錯的)。
*   大小寫有區別 (`age` 和 `Age` 是兩個不同的變數)。
*   不能使用 Python 關鍵字 (例如 `print`, `if`, `for` 等)。
*   建議使用小寫字母和底線來組合單字，例如 `first_name` (這稱為 snake_case，是 Python 社群的慣例喔)。

讓我們來看看幾個例子吧：

```python
# 範例 1: 儲存數字
age = 30
price = 99.5  # 帶小數點的數字稱為浮點數 (float)
quantity = 5

print("我的年齡:", age)
print("商品價格:", price)
print("購買數量:", quantity)

print("-" * 20) # 只是分隔線

# 範例 2: 儲存文字 (字串)
name = "小明"
greeting = "哈囉，程式世界！"
product_name = 'Python 教材' # 你可以用單引號或雙引號來定義字串

print("我的名字:", name)
print("一句問候:", greeting)
print("產品名稱:", product_name)
```

**變數的值是可以改變的！**

就像你可以把箱子裡的東西換掉一樣，變數的值在程式執行過程中也可以被更新：

```python
score = 100
print("原始分數:", score) # 輸出: 原始分數: 100

score = 95 # 重新賦值，現在 score 的值變成了 95
print("新的分數:", score) # 輸出: 新的分數: 95
```

### ➕ ➖ ✖️ ➗ 第二站：基本運算 — 讓你的資料動起來！

學會了儲存資料，接下來就是怎麼『運用』這些資料了！Python 就像一個超級計算器，能幫你做各種數學運算。

**常見的算術運算子：**

| 運算子 | 意義     | 範例         | 結果   | 說明                           |
| :----- | :------- | :----------- | :----- | :----------------------------- |
| `+`    | 加法     | `10 + 5`     | `15`   |                                |
| `-`    | 減法     | `20 - 7`     | `13`   |                                |
| `*`    | 乘法     | `4 * 6`      | `24`   |                                |
| `/`    | 除法     | `10 / 3`     | `3.333...` | **注意：結果會是浮點數**     |
| `//`   | 整數除法 | `10 // 3`    | `3`    | **只取整數部分，捨棄小數**     |
| `%`    | 餘數     | `10 % 3`     | `1`    | **取除法後的餘數**             |
| `**`   | 次方     | `2 ** 3`     | `8`    | `2 的 3 次方 (2*2*2)`          |

跟數學課一樣，Python 也有『先乘除後加減』的規則，你可以用括號 `()` 來改變運算順序。

```python
# 範例 3: 直接進行運算
result_add = 10 + 5
result_sub = 20 - 7
result_mul = 4 * 6
result_div = 10 / 3        # 結果是浮點數: 3.3333333333333335
result_int_div = 10 // 3   # 整數除法: 3
result_mod = 10 % 3        # 餘數: 1
result_power = 2 ** 4      # 2的4次方: 16

print(f"10 + 5 = {result_add}")
print(f"20 - 7 = {result_sub}")
print(f"4 * 6 = {result_mul}")
print(f"10 / 3 = {result_div}")
print(f"10 // 3 = {result_int_div}")
print(f"10 % 3 = {result_mod}")
print(f"2 ** 4 = {result_power}")

# 結合運算與變數
apple_price = 15
orange_price = 20
num_apples = 3
num_oranges = 2

total_cost = (apple_price * num_apples) + (orange_price * num_oranges)
print(f"總共花費: {total_cost} 元") # 輸出: 總共花費: 85 元
```
*(小提醒：這裡的 `f"..."` 是一種叫做 f-string 的格式化字串，能讓你更方便地把變數值嵌入到字串中，非常好用！)*

**文字也可以『相加』喔！(字串串接)**

有趣的是，`+` 運算子不只可以用在數字上，也可以用來連接文字 (字串)，這稱為『字串串接 (String Concatenation)』。

```python
first_name = "程式"
last_name = "小編"

full_name = first_name + last_name
print(full_name) # 輸出: 程式小編

message = "你好，" + full_name + "！歡迎來到 Python 世界！"
print(message)
```
